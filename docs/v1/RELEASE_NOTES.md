# Muse Hub v1.2.0

Get more out of Muse: explore its features, customize an assistant, connect tools, and create a useful workspace.

## Improved in this update

- Six homepage paths for Muse features, specialists, automation, Companion spaces, computer tools, and the resource library.
- Three guided journeys for [everyday planning](../journeys/ORGANIZE_YOUR_DAY.md), [engineering](../journeys/BUILD_AND_AUTOMATE.md), and [creative work](../journeys/CREATE_SOMETHING.md).
- Clear routes to persistent notes, Companion Studio, Signal Trail, and Family Link.
- Shareable resource filters with browser Back and Forward, plus working navigation across Home and Downloads.
- Browser checks for mobile layouts, filtering, keyboard use, and resource links.

## What is included

- **15 individual assistant packages**, each with Main instructions, three subchat guides, selected methods, and a first task.
- **75 skills, 25 workflows, and 100 task starters** for engineering, research, creative work, data, planning, and learning.
- **151 connector guides** with service setup, account requirements, and upstream references.
- **Companion Home** with five rooms, saved room notes, Studio motion controls, and Signal Trail in the Arcade.
- **Daily Desk** for tasks and notes, revisions, reopening, backup, and restoration.
- **Specialist tools** for data, reliability, automation, interface checks, research, engineering, and model experiments.
- **Terminal guidance** for personal Muse chat through `muse-cli` and local toolkit commands.

## Start using it

[Download an assistant](../DOWNLOAD_A_SPECIALIST.md), extract it into its own folder, and open `START_HERE.md`. Give Muse the guide or ZIP with your task, then follow the instructions for Main and the three subchats.

Assistant instructions require no Python. Optional local programs list their requirements in the package. Repository examples use Python 3.12+.

## Downloads and updates

Use the [v1.2.0 release](https://github.com/atlas-origins/muse-ai-agent-presets/releases/tag/v1.2.0) and compare each download with its `SHA256SUMS` entry. Keep your original download and customized working copy separately. Preserve preferences, memory, credentials, and saved databases when updating.
