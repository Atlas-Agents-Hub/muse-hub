# Muse Hub v1.6.0

Build, research, create and automate with a larger library for your personal Muse assistant.

## What is new

- **5242 skills** with supporting references, scripts and examples across engineering, data, research, design, creative work and daily life.
- **396 workflows** with connected steps, named inputs, settings and checks.
- **558 task starters** for complete requests and focused work within a workflow.
- **273 connectors**, including 122 new service adapters with named actions and input fields.
- Updated libraries, setup guides and service selections for all **15 specialists**.
- Searchable subject packs, direct guide links, shareable filters, paginated results and readable subject indexes.

Companion Home, Daily Desk, Studio, Arcade, Family Link and the terminal tools remain part of the toolkit. Use the [51 tool guides](../tools/README.md) to select tools for your task.

## Start using it

[Choose an assistant](../DOWNLOAD_A_SPECIALIST.md), extract its ZIP and open `START_HERE.md`. Configure Main and the three subchats, choose a skill from `PROFILE.md`, and bring your first task. Open `CONNECTORS.md` for the services selected for that specialist.
