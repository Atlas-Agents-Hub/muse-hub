# Keyword Tool: Free SEO Ideas

**Turn search phrases into useful pages**

Find the language people use for a product and assign useful search topics to clear page titles and headings.

**Works well with:** Product Interface Designer, Creative Studio, Coordinator.

## What to bring

- Seed phrases
- Audience and locale
- Current page inventory

## Setup

1. Choose the target country, language, search platform, and a short list of seed phrases.
2. Check the guest quota before making requests.

**Access:** Guest quota; paid plans for additional data.

## Supported functions

| Function | Use it to |
| --- | --- |
| `keywordtool_quota_guest` | Read the guest request quota |
| `keywordtool_suggestions_guest` | Find keyword ideas for a market and platform |

## Workflow

1. Request suggestions for one seed and the chosen market.
2. Group relevant phrases by user intent and discard unrelated results.
3. Assign each group to an existing page or a specific missing guide.
4. Write a title, description, and opening sentence that answer the intent naturally.

## What you get

- Keyword-to-page map
- Proposed titles and descriptions

## Check the result

- Every selected phrase has an intended page and a useful user question.
- Metric values retain their platform, locale, and retrieval date.
