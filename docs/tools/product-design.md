# Product Design

**Audit and improve an important user journey**

Find the points where people lose context, struggle to act, or cannot access a feature, then verify the improved journey.

**Works well with:** Product Interface Designer, Creative Studio, Software Engineer.

## What to bring

- User goal
- Current flow
- Target devices and accessibility needs

## Setup

1. Choose one user journey and provide its URL, app, or runnable project.

**Access:** Host tools and optional generation services.

## Supported functions

| Function | Use it to |
| --- | --- |
| `audit` | Review a rendered user journey |
| `research` | Investigate high-impact product friction |
| `image-to-code` | Implement an approved visual reference |

## Workflow

1. Capture the starting screen and follow the complete task.
2. Record friction with screenshots, concrete consequences, and severity.
3. Implement the most useful correction while preserving the established design language.
4. Repeat the task on the relevant screen sizes and check keyboard and focus behavior.

## What you get

- Evidence-based findings
- Improved screens
- Verified user journey

## Check the result

- The user can complete the target task.
- The final rendered screens match the intended layout and accessible interaction.
