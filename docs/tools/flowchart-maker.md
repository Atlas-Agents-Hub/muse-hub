# Flowchart Maker

**Explain a process with clear decision branches**

Convert a procedure into a flowchart with meaningful decisions, outcomes, and recovery paths.

**Works well with:** Coordinator, Automation Engineer, Learning Coach, Personal Companion, Software Engineer.

## What to bring

- Procedure or step list
- Decision conditions
- Exceptions

## Setup

1. Provide the current process, start and finish conditions, and intended audience.

**Access:** Local tools.

## Supported functions

| Function | Use it to |
| --- | --- |
| `process-flowchart` | Map actions and decisions in a process |
| `flowchart-review` | Inspect a chart for gaps and ambiguity |
| `mermaid-flowchart` | Create an editable text-based flowchart |

## Workflow

1. Identify the entry point, actions, decisions, and terminal outcomes.
2. Give every decision a labeled branch and include the common exception path.
3. Render the diagram in the chosen format.
4. Walk a normal case and an exception case through the diagram and revise ambiguous steps.

## What you get

- Editable flowchart
- Rendered diagram
- Process walkthrough

## Check the result

- Every branch reaches an intended outcome.
- The diagram agrees with the written procedure.
