# MagicPath

**Turn a canvas design into a working component**

Develop a selected canvas component, inspect its rendered result, and install it with its required assets and dependencies.

**Works well with:** Product Interface Designer, Creative Studio, Software Engineer.

## What to bring

- Design or selected component
- Target interaction
- Host framework and constraints

## Setup

1. Choose the MagicPath project or selected component and confirm the available API quota.

**Access:** MagicPath account quota.

## Supported functions

| Function | Use it to |
| --- | --- |
| `get_component_code_context` | Read the current component files and constraints |
| `start_component_code_session` | Start a scoped component revision |
| `view_component` | Inspect the rendered component |
| `get_component_install_plan` | Retrieve its files, imports, assets, and dependencies |

## Workflow

1. Read the selected component, theme, and current code context.
2. Create a scoped component revision for the requested change.
3. Build and inspect the rendered preview, then refine any layout or interaction defects.
4. Retrieve the install plan and integrate the files, assets, imports, and dependencies into the host project.

## What you get

- Working component
- Rendered preview
- Integration files and instructions

## Check the result

- The preview satisfies the requested interaction and layout.
- The installed component builds and works in the host application.
