# Atlas Omnium

**Choose the right connection for each job**

Route a task to the appropriate connected service, then confirm the resulting file, record, or application state.

**Works well with:** All specialists.

## What to bring

- Task and desired result
- Service or resource identifier
- Existing authorization and budget

## Setup

1. Select the requested service connection in the host assistant and confirm the intended project or account.

**Access:** Connected service plans.

## Supported functions

| Function | Use it to |
| --- | --- |
| `omnium-control` | Select and coordinate the appropriate connected service |
| `omnium-wolfram-analysis` | Use computation for quantitative decisions |

## Workflow

1. Find the smallest available operation that can produce the requested result.
2. Read the current resource and match its identity to the task.
3. Use the chosen service operation within the existing scope.
4. Read back the resulting resource and attach its link or identifier to the handoff.

## What you get

- Completed service operation
- Result link or resource identifier
- Concise handoff

## Check the result

- The connection and destination match the task.
- A read-back confirms the intended change or retrieved result.
