# OpenSEO

**Fix the pages that search engines struggle to use**

Turn crawl findings into targeted fixes for page titles, indexing, canonical URLs, internal links, and content coverage.

**Works well with:** Product Interface Designer, Infrastructure Reliability Engineer, Creative Studio.

## What to bring

- Public website URL
- Key pages
- Existing crawl or search data

## Setup

1. Select the website and its existing OpenSEO project.
2. Check account limits before adding paid keyword or SERP research.

**Access:** Account plan and research credits.

## Supported functions

| Function | Use it to |
| --- | --- |
| `seo-audit` | Review technical and on-page search issues |
| `keyword-clustering` | Group search intent and map it to pages |
| `keyword-research` | Evaluate topic and query opportunities |

## Workflow

1. Inspect the latest crawl and affected URLs.
2. Group duplicate findings by the template or component that owns them.
3. Fix the highest-impact cause and rebuild the affected pages.
4. Recheck those URLs and compare the result with the original findings.

## What you get

- Prioritized page fixes
- Updated metadata and links
- Before-and-after audit

## Check the result

- Canonical and indexability checks pass on the intended pages.
- Each claimed fix is supported by a refreshed result or direct page inspection.
