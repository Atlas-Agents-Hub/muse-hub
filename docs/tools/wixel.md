# Wixel

**Create a coordinated set of visual assets**

Generate or refine logos, images, presentations, invitations, and other visual assets using a clear brief and consistent style.

**Works well with:** Creative Studio, Product Interface Designer, Personal Companion.

## What to bring

- Creative brief
- Approved text
- Brand assets and output size

## Setup

1. Choose the intended asset type, dimensions, and brand kit; check available generation credits.

**Access:** Generation credits; image conversion is free.

## Supported functions

| Function | Use it to |
| --- | --- |
| `send_wixel_message` | Create or revise the requested visual asset |
| `get_wixel_asset_result` | Display the produced asset |
| `wixel_convert_image` | Convert an image to PNG or JPEG |

## Workflow

1. Send one complete brief and retain the returned conversation and task identifiers.
2. Answer any required style or content question.
3. Review the generated result and request a precise revision when necessary.
4. Download the delivered assets and inspect the final dimensions and typography.

## What you get

- Visual asset set
- Editable or exported files
- Approved variations

## Check the result

- Required text is legible and correct.
- Assets use the requested dimensions, style, and brand elements.
