# Wolfram

**Check a quantitative result with reproducible computation**

Evaluate equations, units, data, or optimization questions and keep the inputs and assumptions attached to the result.

**Works well with:** Research Evaluator, Learning Coach, Model Builder, Data Engineering Architect, Claims Adjudicator, Garden Companion.

## What to bring

- Equation or data
- Units and domain
- Desired result and tolerance

## Setup

1. State the mathematical question, units, assumptions, and required precision.

**Access:** Connected Wolfram service.

## Supported functions

| Function | Use it to |
| --- | --- |
| `wolframcontext` | Find relevant computational context |
| `wolframalpha` | Evaluate a natural-language computational question |
| `wolframlanguageevaluator` | Evaluate an explicit Wolfram Language expression |

## Workflow

1. Retrieve the relevant computational context.
2. Formulate the calculation with explicit units and assumptions.
3. Evaluate it with Wolfram|Alpha or Wolfram Language.
4. Check limiting cases, dimensional consistency, or an independent numerical example.

## What you get

- Computed result
- Reusable expression
- Assumptions and validation

## Check the result

- Units and domains are consistent.
- A boundary or independent calculation agrees within the stated tolerance.
