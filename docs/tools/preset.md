# Preset API Skills

**Build a dashboard with tested data access**

Connect a dataset, define useful metrics, build a dashboard, and check what each viewer is allowed to see.

**Works well with:** Data Engineering Architect, Software Engineer, Adversarial Verifier, Coordinator.

## What to bring

- Dataset and business questions
- Metric definitions
- Viewer and tenant rules

## Setup

1. Select the Preset workspace and connection; prepare representative viewer roles.

**Access:** Preset workspace plan; Superset hosting varies.

## Supported functions

| Function | Use it to |
| --- | --- |
| `preset-datasets` | Configure the dataset and metrics |
| `preset-dashboards` | Build a dashboard |
| `preset-embedded-rls` | Review access rules for embedded dashboards |

## Workflow

1. Inspect the database connection, dataset columns, and existing metrics.
2. Build charts around the agreed definitions and filters.
3. Arrange a dashboard that answers the primary questions.
4. Test filters, row-level access, and embedded views with representative roles.

## What you get

- Dataset and metric configuration
- Dashboard
- Access test results

## Check the result

- Dashboard totals agree with a reference query.
- Each viewer sees the intended rows and controls.
