# TEAM 30 — AI Company OS

**Give each part of a project a clear owner**

Match a project to useful specialist roles and create a practical sequence of deliverables and review points.

**Works well with:** Coordinator, Automation Engineer, Software Engineer, Creative Studio.

## What to bring

- Project brief
- Constraints and dependencies
- Available specialists

## Setup

1. Provide the project goal, constraints, available people or assistants, and desired finish date.

**Access:** Provider access.

## Supported functions

| Function | Use it to |
| --- | --- |
| `team30_route_task` | Choose a suitable specialist role |
| `team30_build_project_plan` | Define a project sequence and completion criteria |
| `team30_check_action_gate` | Assess the authorization needed for a proposed action |

## Workflow

1. Route the goal to the most relevant role.
2. Build a plan with deliverables, dependencies, and a clear completion check for each phase.
3. Assign each workstream to one owner and define the handoff artifact.
4. Check consequential actions against the existing authorization when they become ready.

## What you get

- Project plan
- Specialist assignments
- Handoff checklist

## Check the result

- Every deliverable has an owner and a completion check.
- The next action can begin with the available inputs.
