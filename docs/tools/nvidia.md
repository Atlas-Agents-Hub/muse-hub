# NVIDIA Skills

**Select the right NVIDIA workflow for the hardware**

Find the relevant NVIDIA workflow for inference, data processing, simulation, or device work and measure the result on the target system.

**Works well with:** Model Builder, Infrastructure Reliability Engineer, Data Engineering Architect, Creative Studio, Software Engineer.

## What to bring

- Hardware and software versions
- Workload and baseline
- Performance or correctness goal

## Setup

1. Identify the exact GPU or device, driver, operating system, and task.
2. Use the current NVIDIA skills catalog to select the applicable package.

**Access:** Local hardware; hosted services use their own plans.

## Supported functions

| Function | Use it to |
| --- | --- |
| `nvidia-skill-finder` | Select the relevant NVIDIA skill from the current product catalog |

## Workflow

1. Match the task to the specific NVIDIA product and skill.
2. Check its prerequisites against the target hardware.
3. Run the smallest representative workload and retain its configuration.
4. Change one relevant setting and compare accuracy, latency, throughput, or memory against the baseline.

## What you get

- Selected NVIDIA workflow
- Environment record
- Measured comparison

## Check the result

- The chosen skill supports the actual hardware and product.
- Improvements are measured under the same workload conditions.
