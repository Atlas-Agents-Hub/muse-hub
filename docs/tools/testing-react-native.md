# Testing React Native Apps

**Test a mobile feature from component to device**

Combine React Native component assertions with a real device or simulator walkthrough of the user flow.

**Works well with:** Software Engineer, Adversarial Verifier, Product Interface Designer.

## What to bring

- Feature and acceptance cases
- App build
- Target platform

## Setup

1. Use the project’s React Native Testing Library version and an available simulator or device.

**Access:** Local tools.

## Supported functions

| Function | Use it to |
| --- | --- |
| `react-native-testing` | Test components with realistic user interactions |
| `agent-device` | Inspect and operate the target simulator or device |
| `dogfood` | Explore the app and collect reproducible issues |

## Workflow

1. Write a component test using accessible queries and realistic user interactions.
2. Cover loading, success, and failure states relevant to the feature.
3. Run the same user journey on the selected device and capture key screens.
4. Reproduce any issue with exact steps and attach the relevant logs or recording.

## What you get

- Component tests
- Device walkthrough
- Reproducible issue report

## Check the result

- Tests assert the behavior a user can observe.
- The target device reaches the expected final state.
