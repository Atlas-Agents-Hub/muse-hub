# Windowisp

**Add a desktop companion to a focus session**

Use a Windows desktop pet, its playroom, and simple status reactions during personal work and learning sessions.

**Works well with:** Personal Companion, Learning Coach, Creative Studio.

## What to bring

- Requested pet mode
- Optional supported status event

## Setup

1. Use the Windowisp launcher on a Windows desktop and choose the requested mode.

**Access:** Local tools.

## Supported functions

| Function | Use it to |
| --- | --- |
| `game-mode` | Choose desktop-pet, playroom, and supported status-reaction modes |

## Workflow

1. Launch or connect to the existing pet through its supported launcher.
2. Choose a single mode such as playroom, movement control, or a status reaction.
3. Check the visible state and the relevant keyboard controls.
4. Pause or close the companion when the session ends.

## What you get

- Configured desktop companion
- Session controls

## Check the result

- The selected mode appears on the desktop.
- Status reactions use the supported event names and leave task content private.
