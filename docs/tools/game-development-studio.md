# Game Development Studio

**Bring a game asset into a tested scene**

Produce or select a game asset, check its formats and materials, and verify it in a reproducible scene.

**Works well with:** Creative Studio, Software Engineer, Product Interface Designer.

## What to bring

- Asset brief
- Target formats and budgets
- Reference scene

## Setup

1. Prepare the local game-dev tools and the target engine or asset pipeline.

**Access:** Local tools; optional generation providers use credits.

## Supported functions

| Function | Use it to |
| --- | --- |
| `game-asset-production` | Create and normalize game assets |
| `game-asset-vendoring` | Admit a checked asset package into a project |
| `game-visual-debugging` | Compare a reproducible rendered scene |
| `game-performance-optimization` | Measure a focused performance change |

## Workflow

1. Create or select the asset and check the usage rights for included materials.
2. Normalize scale, orientation, textures, and file formats.
3. Package the asset with the metadata the project needs.
4. Render the reference scene and compare appearance and performance with the declared target.

## What you get

- Validated asset package
- Preview scene or capture
- Asset metadata

## Check the result

- The asset loads with expected materials and scale.
- The scene meets its agreed visual and performance limits.
