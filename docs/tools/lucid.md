# Lucid

**Maintain an editable architecture or process diagram**

Create or update a shared diagram from real architecture, database, or process information and keep its editable source useful.

**Works well with:** Data Engineering Architect, Software Engineer, Product Interface Designer, Coordinator, Automation Engineer, Research Evaluator.

## What to bring

- Source architecture, schema, or process
- Document or destination
- Required notation

## Setup

1. Connect Lucid and choose the intended document or destination.

**Access:** Lucid account plan.

## Supported functions

| Function | Use it to |
| --- | --- |
| `fetch` | Read an existing document |
| `lucid_create_diagram_from_specification` | Create an editable diagram from a structured specification |
| `lucid_validate_diagram_specification` | Check text and layout before document creation |
| `lucid_export_document_as_png` | Export a rendered preview |

## Workflow

1. Read the existing diagram or select the appropriate supported diagram format.
2. Build or update the diagram using the source relationships.
3. Validate layout and text before finalizing the document.
4. Export a preview and inspect the result while retaining the editable document link.

## What you get

- Editable Lucid document
- Preview export
- Source-to-diagram notes

## Check the result

- Entities and connections match the supplied source.
- The exported preview is legible and complete.
