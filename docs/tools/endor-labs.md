# Endor Labs Agent Kit

**Turn a dependency finding into a verified repair**

Investigate dependency and code findings, choose a practical remediation, and verify the affected build and behavior.

**Works well with:** Adversarial Verifier, Infrastructure Reliability Engineer, Software Engineer, Reverse Engineering Researcher.

## What to bring

- Finding and affected component
- Repository and lockfile
- Application use of the dependency

## Setup

1. Connect the relevant Endor organization and project or prepare the supported CLI environment.

**Access:** Endor Labs account plan.

## Supported functions

| Function | Use it to |
| --- | --- |
| `findings-browser` | Find and inspect relevant security findings |
| `dependency-reviewer` | Review dependency changes |
| `sca-remediation` | Prepare and verify a dependency repair |

## Workflow

1. Read the finding and identify the affected version and code path.
2. Check available fixes, upgrade impact, and any relevant reachability evidence.
3. Apply the smallest suitable dependency or code repair.
4. Run the affected tests and refresh the finding against the changed revision.

## What you get

- Remediation patch
- Dependency change record
- Verification result

## Check the result

- The affected component is fixed in the resolved dependency graph.
- The application behavior and relevant tests still pass.
