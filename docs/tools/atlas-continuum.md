# Atlas Continuum

**Resume a project with its decisions intact**

Keep long projects moving across sessions with a concise work record, clear acceptance checks, and an exact next action.

**Works well with:** All specialists.

## What to bring

- Goal and acceptance checks
- Current files or repository
- Last handoff and test results

## Setup

1. Open the project workspace and its saved handoff; select the Continuum skills in the host assistant.

**Access:** Local tools.

## Supported functions

| Function | Use it to |
| --- | --- |
| `atlas-resume-recovery` | Reconcile the saved handoff with current files |
| `atlas-execution-cycle` | Complete a focused unit of work |
| `atlas-verification` | Verify the delivered result |

## Workflow

1. Compare the saved handoff with the current files, branch, and working changes.
2. Choose the next incomplete dependency and record the expected result before editing.
3. Run the relevant check against the changed artifact and save the result with its revision.
4. Save decisions, failed attempts, current files, and the next executable step in the handoff.

## What you get

- Updated work record
- Verified deliverable
- Restart instructions

## Check the result

- The handoff identifies the actual current revision and changes.
- A fresh session can locate the deliverable and run the next step without reconstructing chat history.
