# Pablooo.club Benchmark library

**Find proven interface patterns for a screen**

Explore real product screenshots to understand useful layouts, interactions, and content patterns for a specific user task.

**Works well with:** Product Interface Designer, Creative Studio.

## What to bring

- Screen goal
- Audience
- Target device

## Setup

1. Describe the screen as a user task and choose mobile or desktop when it matters.

**Access:** Free screenshot search and reference library.

## Supported functions

| Function | Use it to |
| --- | --- |
| `search_screenshots` | Find screen references for a user task |
| `get_screenshot_base64data` | Inspect a selected screenshot |
| `search_facet_values` | Discover valid filters when a search needs refinement |

## Workflow

1. Search by the user task without facet filters on the first request.
2. Select a few relevant screenshots and inspect their details.
3. Compare information hierarchy, primary action, empty states, and error handling.
4. Translate the useful principles into an original design brief for the product.

## What you get

- Reference shortlist
- Pattern comparison
- Original screen brief

## Check the result

- Each design decision connects to the product task.
- Reference imagery is used for analysis and the delivered interface uses original assets and copy.
