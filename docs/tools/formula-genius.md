# Formula Genius

**Build a spreadsheet formula that survives edge cases**

Create or debug spreadsheet formulas using explicit examples, application compatibility, and a checked workbook when needed.

**Works well with:** Data Engineering Architect, Personal Companion, Coordinator, Learning Coach, Garden Companion.

## What to bring

- Formula or calculation request
- Sample rows
- Expected results

## Setup

1. Identify Excel or Google Sheets, its version and locale, and the cells involved.

**Access:** Guest examples and account credits; features vary by plan.

## Supported functions

| Function | Use it to |
| --- | --- |
| `generate_formula` | Write a formula for the stated application and ranges |
| `check_formula_samples` | Compare the formula with supplied expected samples |
| `check_workbook_health` | Inspect a workbook for common structural problems |
| `build_workbook` | Create a workbook with checked sample formulas |

## Workflow

1. State the calculation rule and choose the appropriate formula for the application version.
2. Generate or repair the formula.
3. Check normal, blank, duplicate, and boundary cases with expected results.
4. Place the formula in the intended workbook and inspect the surrounding totals or references.

## What you get

- Working formula
- Sample-case results
- Workbook when requested

## Check the result

- The formula matches the supplied expected results.
- Separators, functions, and references work in the target application.
