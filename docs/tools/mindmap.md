# MindMap

**Organize a topic into a navigable outline**

Turn a topic, study plan, or project brief into a clear interactive hierarchy that is easy to explore.

**Works well with:** Learning Coach, Personal Companion, Coordinator, Research Evaluator, Garden Companion.

## What to bring

- Topic or notes
- Desired depth
- Audience

## Setup

1. Choose one root topic and provide the notes or ideas to organize.

**Access:** Provider access.

## Supported functions

| Function | Use it to |
| --- | --- |
| `interactive_mind_map_for_visual_plans` | Render a Markdown hierarchy as an interactive mind map |

## Workflow

1. Group related ideas under a small set of meaningful branches.
2. Write one root heading and a consistently indented bullet hierarchy.
3. Render the interactive mind map.
4. Check that every source idea has an appropriate place and remove duplicate branches.

## What you get

- Interactive mind map
- Reusable Markdown outline

## Check the result

- The input contains one root and a valid hierarchy.
- Branch labels are concise and preserve the meaning of the notes.
