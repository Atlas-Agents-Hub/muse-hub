# TinyFish

**Collect a consistent set of web research results**

Find relevant pages, extract comparable fields, and complete a defined browser task with a clear final result.

**Works well with:** Research Evaluator, Automation Engineer, Claims Adjudicator, Coordinator, Personal Companion, Garden Companion.

## What to bring

- Research question or browser task
- Allowed sites
- Required output fields

## Setup

1. Specify the sites, fields, and number of results; select a browser profile only for a task that needs that account.

**Access:** Free search and fetch; browser automation and monitoring use the account wallet.

## Supported functions

| Function | Use it to |
| --- | --- |
| `search` | Find relevant public web pages |
| `fetch_content` | Read and extract information from a specified page |
| `run_web_automation` | Carry out a defined browser interaction |

## Workflow

1. Search for the most relevant pages or open the provided URLs.
2. Fetch the supporting content and retain page URLs for each result.
3. For interactive work, define the exact destination and observable completion state before starting the browser run.
4. Collect the results, deduplicate them, and inspect a sample against the original pages.

## What you get

- Cited research table or completed browser result
- Source URLs
- Run identifier when used

## Check the result

- Required fields are present and trace to their source pages.
- Interactive work ends in the requested observable state.
