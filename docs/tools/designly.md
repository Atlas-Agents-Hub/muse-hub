# Designly

**Develop a coherent visual campaign**

Turn a brand brief into a consistent art direction, typography, composition, and set of campaign assets.

**Works well with:** Creative Studio, Product Interface Designer, Coordinator.

## What to bring

- Campaign objective
- Brand and audience
- Asset list and dimensions

## Setup

1. Provide approved brand material, audience, format requirements, and usable reference images.

**Access:** Host design tools and chosen generation services.

## Supported functions

| Function | Use it to |
| --- | --- |
| `creative-strategy` | Develop the creative direction |
| `typography-director` | Choose and review typography |
| `composition-director` | Shape the layout and visual hierarchy |
| `visual-qa` | Review the completed asset set |

## Workflow

1. Define the campaign idea and the visual rules that express it.
2. Choose typography, palette, composition, and image treatment for each format.
3. Produce the selected asset variations while preserving the shared direction.
4. Review consistency, text legibility, cropping, and export quality across the complete set.

## What you get

- Art-direction brief
- Campaign asset set
- Visual review

## Check the result

- Every asset expresses the same approved campaign idea.
- Text, colors, and spacing remain consistent across formats.
