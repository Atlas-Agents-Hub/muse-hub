# KaTeX Error Fixer

**Keep equations correct from source to screen**

Repair broken mathematical notation at the layer that owns it and check the resulting learning page.

**Works well with:** Learning Coach, Research Evaluator, Product Interface Designer, Software Engineer.

## What to bring

- Approved equations
- Failing page or data item
- Build and renderer configuration

## Setup

1. Provide the approved mathematical source, affected content, and a runnable page or build.

**Access:** Local tools.

## Supported functions

| Function | Use it to |
| --- | --- |
| `math-content-integrity` | Find and repair equation rendering defects across the content pipeline |

## Workflow

1. Compare the source notation with the stored content and rendered page.
2. Separate prose and currency from inline and display mathematics.
3. Correct the responsible source, transformation, or renderer and rebuild.
4. Inspect the page for missing equations, raw TeX, malformed delimiters, and layout clipping.

## What you get

- Corrected math content
- Rendered verification
- Regression fixture

## Check the result

- Symbols and equation order match the approved source.
- Currency, prose, inline equations, and display equations render correctly.
