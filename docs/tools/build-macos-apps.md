# Build macOS Apps

**Build and test a native macOS application**

Develop SwiftUI or AppKit features, diagnose Xcode and SwiftPM failures, and prepare a working macOS app package.

**Works well with:** Software Engineer, Adversarial Verifier, Product Interface Designer, Infrastructure Reliability Engineer.

## What to bring

- Xcode project or Swift package
- Feature or failing case
- Target macOS version

## Setup

1. Use a macOS host with the required Xcode or Swift toolchain and the project dependencies.

**Access:** macOS host; distribution account requirements vary.

## Supported functions

| Function | Use it to |
| --- | --- |
| `build-run-debug` | Build and inspect the running macOS app |
| `test-triage` | Narrow a failing Xcode or SwiftPM test |
| `signing-entitlements` | Inspect signing and entitlement issues |
| `packaging-notarization` | Validate distribution packaging |

## Workflow

1. Select the correct scheme or package target and reproduce the build or runtime behavior.
2. Implement the feature using the project’s scene, state, and window patterns.
3. Run relevant tests and inspect the resulting application.
4. For distribution work, inspect signing, entitlements, packaging, and notarization results.

## What you get

- Working app or package
- Test and build results
- Distribution checks when requested

## Check the result

- The target builds with the specified toolchain.
- The feature works in the running macOS app.
