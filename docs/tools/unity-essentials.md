# Unity Essentials

**Implement a Unity feature with a reproducible scene**

Investigate gameplay defects or add features with a small scene, stable project settings, and an actual build check.

**Works well with:** Software Engineer, Creative Studio, Adversarial Verifier.

## What to bring

- Project and editor version
- Scene and reproduction steps
- Expected gameplay behavior

## Setup

1. Open the Unity project with its recorded editor version and required packages.

**Access:** Unity plan and target platform requirements.

## Supported functions

| Function | Use it to |
| --- | --- |
| `unity-project-onboarding` | Inspect the project and editor requirements |
| `unity-feature-implementation` | Implement a focused gameplay feature |
| `unity-build-validation` | Check the target build |

## Workflow

1. Inspect the project settings, scene objects, and relevant scripts.
2. Reproduce the feature or defect in a small scene.
3. Implement the focused change and check editor logs and play behavior.
4. Run the project’s relevant tests and validate the intended build target.

## What you get

- Working Unity feature
- Reproduction scene
- Test or build results

## Check the result

- The behavior works after reopening the scene.
- The intended build completes and retains the tested behavior.
