# Gum

**Create a precise editable technical figure**

Build diagrams, plots, mathematical figures, and slides from editable JSX with reproducible exports.

**Works well with:** Research Evaluator, Learning Coach, Creative Studio, Data Engineering Architect, Product Interface Designer.

## What to bring

- Figure purpose
- Verified data or equations
- Dimensions and labels

## Setup

1. Install the Gum renderer and select the required SVG, PNG, or PDF output.

**Access:** Local tools.

## Supported functions

| Function | Use it to |
| --- | --- |
| `gum-jsx` | Author and render editable technical figures |

## Workflow

1. Choose the figure type and define units, axes, labels, and relationships.
2. Write the Gum JSX using its supported drawing components.
3. Render the figure and inspect label placement, bounds, and visual hierarchy.
4. Export the source and final figure together.

## What you get

- Editable JSX
- Rendered figure
- Export files

## Check the result

- Numbers, units, and relationships match the inputs.
- Text remains readable and unclipped at the intended display size.
