# Connect tools and services

Find the service you need among [273 connectors](connectors/README.md). Each entry links to its setup guide, available operations, and account requirements.

## Set up a connection

1. Open the service's guide and confirm the account you want to use.
2. Follow its supported custom-connector or tool setup flow.
3. Select the operations and permissions needed for your work.
4. Run a small check, then inspect its result in the original service.

Keep credentials in the platform's secure connection flow. Use your assistant's supported terminal, browser, desktop, or SSH tools for work on an authorized computer. [The terminal guide](TERMINAL.md) includes personal Muse chat and local toolkit commands.

## Work across specialists

[Family Link](FAMILY_LINK.md) helps prepare a task handoff with the context, receiving role, and expected result. Review the record before sharing through your chosen service connection. Keep each assistant's personal context and memory in its own workspace.

## Recover an interrupted action

If an action may have completed but its response is missing, check its original service status before retrying. Keep the operation or message ID so the result can be reconciled. Confirm the target account and scope after a permission change.
