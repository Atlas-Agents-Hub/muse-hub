# Download a Muse specialist

**One ZIP = one Muse assistant.** Choose the specialist you want, download its ZIP, and follow the START_HERE.md inside.

Every ZIP includes Main documents, three subchat folders, selected skills and workflows. You do not need Python to configure the assistant. Any optional local program has its own instructions.

## Set up your assistant

1. Download one specialist ZIP above.
2. Unzip it and open START_HERE.md.
3. Create a dedicated Muse assistant for that specialist and use its Main documents.
4. Create its three subchats inside the same assistant, using the matching subchats folders.
5. Ask the first example question in Main.

**Keeping specialists separate:** If you want two specialists, give each its own Muse assistant/account, Main and subchats. Do not combine their private memories.

**Checksums:** [SHA256SUMS.txt](https://github.com/atlas-origins/muse-ai-agent-presets/releases/download/v1.1.0/SHA256SUMS.txt) lets you check the exact ZIP bytes.

**Apps and actions:** The ZIP contains configuration and optional local code, not login credentials or permission to connect to other apps. Those connections still use Muse?s own controls.
