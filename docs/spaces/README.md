# Muse Hub Space templates

Start with an app you can run, customize, and build on. Pick a workspace and follow its setup guide.

| Template | What you can do | Source |
| --- | --- | --- |
| [Muse Planner](MUSE_PLANNER.md) | Capture ideas, organize projects and next actions, set up routines, review calendars, and back up a workspace. | [TypeScript app, API, and database migrations](../../examples/gtd_space) |
| [Muse Task Board](TASK_BOARD.md) | Add and move cards, edit or undo a removal, and import or export board data. | [Web interface and Python service](../../examples/task_board) |
| [Daily Desk](DAILY_DESK.md) | Manage daily tasks and notes, resolve conflicting edits, and back up or restore saved work. | [Python launcher](../../examples/daily_desk.py) |

[Companion Home](../COMPANION_HOME.md) gives you five rooms for notes, garden observations, creative experiments, focused work, and play. [Open the browser workspace source](../../examples/companion_home).
