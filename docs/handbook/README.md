# Muse operating handbook

Having trouble getting the assistant to use the right context, keep documents or follow a specialist workflow? Start with the problem below. Each guide covers a specific task and how to check the result.

## Fix a problem

- **Relevant information is missing:** [Load the right context](context-loading.md). Select source material and verify that the current conversation actually has it.
- **A skill is available but unused:** [Select and use a skill](skill-setup.md). Prepare its instructions, configure the supported host entry point and check a harmless example.
- **A side chat keeps losing its task:** [Build a workroom](subchat-workrooms.md). Give the conversation a scope, current files, working instructions and a handoff record.
- **Important material disappears between sessions:** [Keep documents recoverable](durable-documents.md). Save, read back, export and restore documents instead of assuming context memory is storage.
- **A local example is mistaken for a live integration:** [Understand capability boundaries](source-and-host-capabilities.md). Separate source, execution, account access and durable results.

## Use the working Personal Companion tool

[Daily Desk](../spaces/DAILY_DESK.md) is implemented locally. It saves tasks and notes in SQLite, rejects stale edits, and supports checked backup and restore. [The original design notes](daily-desk-design.md) explain its planning history; use the application guide for current commands.
