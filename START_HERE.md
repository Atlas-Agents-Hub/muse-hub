# Start with Muse Hub

This toolkit includes all 15 specialists, the skill and workflow collection, and the Python tools.

## Use a specialist with Muse

Open [Getting started](docs/GETTING_STARTED.md), choose a specialist, and give Muse its kit together with your current task. The [download directory](https://atlas-origins.github.io/muse-ai-agent-presets/downloads.html) has a separate ZIP for every specialist, skill, and workflow.

## Run the included tools

Open a terminal in this extracted folder. With Python 3.12 or newer, try:

```sh
python -B tools/muse_collection.py demo data-engineer
```

The [terminal guide](docs/TERMINAL.md) covers more commands, Muse chat from the command line, and your local notebook. [The README](README.md) introduces the full collection.

## Check your download

Compare the ZIP's SHA-256 digest with `SHA256SUMS` on the [v1.1.0 release page](https://github.com/atlas-origins/muse-ai-agent-presets/releases/tag/v1.1.0). Keep the extracted toolkit in its own folder so updates preserve your existing work.
