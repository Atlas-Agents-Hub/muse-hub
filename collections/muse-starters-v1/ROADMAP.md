# Choose the next library improvement

Start with a task someone is trying to finish. Look for the closest skill, workflow, and specialist, then identify the missing step or unreliable result.

## Improve an existing method

When a method already covers the task, strengthen its input guidance, example, decision points, tool support, or recovery instructions. Test the changed method on the task that exposed the gap and a representative failure case.

## Add a useful skill

Create a new skill when the task needs a distinct method and output. Give it a clear name, stable ID, required inputs, steps, an example, and a way to check the result. Include supporting files and executable tools when they add practical value.

## Connect the pieces

Add the skill to relevant specialists and compose it with related methods into a workflow. Choose an understandable starting task so people can use it without assembling a large instruction set themselves.

## Make it easy to find and use

Update the searchable library, specialist guides, workflow references, and ZIP packages together. Check that the download includes its setup instructions and required files, and that the published links point to the matching release.

## Keep quality visible

Inspect the result, improve confusing instructions, and retain a regression example for failures worth preventing. Use the current [inventory](COUNTS.json) to understand coverage and [practice guide](EVALUATION.md) to evaluate a result.
