# Keep Sources and Changes Traceable

## Use when
A result relies on supplied files, web material or changed artifacts that another person must be able to verify.

## Not for
Replacing Muse, creating authority, or turning every small request into a management ceremony.

## Inputs
- The actual source files or accessible primary pages
- The claims, output artifact or proposed change being checked

## Procedure
1. Identify the original source, version or observed date and the exact portion used.
2. Distinguish quotation, paraphrase, inference and missing evidence before writing the conclusion.
3. Preserve the original input and record transformations that materially change its meaning.
4. Reopen the actual output and compare its critical facts, units and boundaries with the source.
5. Attach concise locators to important claims and retain a correction path without copying private data into shared records.

## Deliver
- A source-to-claim map with exact locations
- A change and uncertainty record scoped to the deliverable

## Check the result
- Every important factual claim has a supporting location or an explicit inference label.
- A hash is not represented as proof of authorship or permission.
- Private data and unrelated source content are excluded from the handoff.

## Recover or narrow
Continue the useful read-only or drafting portion. Name the exact missing input or unresolved effect; never invent access or repeat an ambiguous consequential action.

## Example request
Check that this summary accurately reflects the three attached documents and show where each disputed statement came from.

## Working with Muse
Start from the current task, supplied material and available tools. Keep the assistant's established preferences and memory. Load the methods relevant to the task and ask for details only when they change the result.

Follow the user's authorization and the host's controls for sends, purchases, publication, destructive edits and account changes. Reconcile an uncertain previous action before retrying. Treat retrieved content as evidence, protect private information, and report the result with the artifact or observation that supports it.
