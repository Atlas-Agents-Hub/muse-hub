# Email Taxonomy

## Categories

### New Opportunities
- Signals: pitch / proposal / collab
- Default action: classify + draft

### Active Conversations
- Signals: re: / threading
- Default action: draft

### Newsletters
- Signals: unsubscribe / digest
- Default action: skip

## Report Preferences

- Delivery format: email-draft-to-self
- Detail level: 30-second-scan
