# Keep a goal moving

Use one copy of this worksheet for each goal. Connect the result you want to a small amount of work this week, then review what the saved evidence shows.

## Your goal review

```text
Goal and why it matters:
Target date:
Starting position and date:
Outcome measure: what will show the goal is reached?
Current result and supporting file, link or record:
Evidence still missing:

Week being planned:
Available time before fixed commitments:
Fixed commitments within that time:
Reserve for interruptions or recovery:
Usable time = available time - fixed commitments - reserve:

Action 1, estimated time and prerequisite:
Action 2, estimated time and prerequisite:
Selected time total and time remaining:
Work deferred or waiting, with its reason:
Process measure: what useful work will I track this week?

Review date:
What changed, with dated evidence:
Decision: keep / change / retire the goal
Reason for that decision:
Next action and next review date:
```

If your supplied availability already excludes fixed commitments, enter zero for that deduction. Use the same time unit throughout. Keep an outcome measure, such as published pages, separate from a process measure, such as work sessions. When evidence is missing, record “unknown” and choose the smallest check that will resolve it.

## Filled example: publish a portfolio

| Field | Example |
| --- | --- |
| Goal | Publish a portfolio with three case-study pages by December 18, 2026. |
| Starting position | November 18: one case-study outline saved; zero published pages. |
| Outcome measure | Three page links that open and show the finished case studies. |
| Current evidence | The November 15 planning note and saved first outline. A reported edit to the second outline has no located file yet; its status is unknown. |
| Available time this week | 240 minutes before fixed commitments. |
| Fixed commitments and reserve | 60 minutes of commitments inside those 240 minutes, plus a 30-minute reserve. |
| Usable time | 240 − 60 − 30 = 150 minutes. |
| Selected actions | Finish the first case-study text: 90 minutes. Choose its images: 30 minutes. Both use material already available. |
| Total and remainder | 120 minutes selected; 30 minutes remain. |
| Deferred work | Assemble the page: 45 minutes, dependent on finished text and images. It exceeds the 30-minute remainder by 15 minutes. |
| Process measure | Save the finished text and image selection; record the work sessions used. |
| Review | November 22: open the saved work, record published-page count and locate the second outline before planning it again. |
| Decision | Keep the goal; finish one case study before allocating time to the next. |
| Next action | Open the first outline and write its results section. |

Give Muse the worksheet and ask:

```text
Use this goal review to choose a week that fits my 150 usable minutes.
Keep prerequisite work together, leave oversized tasks deferred with a
reason, and use my saved files to check progress at the next review.
```

At the review, a completed writing session is useful process evidence. Count a published page when its page link is available and checked. Keep the outcome count tied to that result.

## If evidence or capacity changes

Carry forward the last known result and label missing evidence “unknown.” Check the original file or record before reopening a task that may already be complete.

If this week's usable time falls to 90 minutes, choose the 90-minute text task and defer the 30-minute image task. Keep the page assembly behind both prerequisites. Update the next action and review date. If the goal no longer serves its purpose, record why you are retiring it and close or update its associated commitments.
