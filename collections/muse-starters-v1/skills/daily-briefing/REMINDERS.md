# Plan a reminder and its follow-up

Copy this worksheet when a task needs a one-time reminder or a recurring check-in. Keep the confirmed schedule with the task so it is easy to find, change or finish later.

## Your reminder

```text
Task or outcome:
Reminder message:
Assistant or service:
Existing reminder title and ID, if available:

First date and local time:
Time zone, such as Europe/London:
Repeat interval, or one-time:
When to review or stop the recurrence:

What will show the task is complete:
Where to keep that result:
What to do at the next check-in if it is unfinished:

Requested action: create / change / cancel
Confirmation received:
Next occurrence shown in the active schedule:
Last checked at:
```

Use a full date and named time zone when requesting the reminder. For a repeating local time, check the next occurrence after a clock change or a move to another time zone. Record a reminder ID if the service supplies one; otherwise keep its title, assistant and schedule together.

[Muse's reminder guide](https://www.meta.com/help/superintelligence/1484325780075655/) covers creating, viewing, changing and canceling reminders. Recurring tasks continue until you cancel them. Use your review date to decide when to update or cancel the existing schedule, then check its confirmation and **Upcoming** entry.

## Filled example: a weekly review

| Field | Example |
| --- | --- |
| Task | Choose three priorities for the coming week. |
| Reminder message | Review last week, check the portfolio goal and choose the next three priorities. |
| Assistant and title | Personal Companion · Weekly review |
| First occurrence | November 22, 2026, at 18:00, Europe/London |
| Repeat | Every Sunday at 18:00, Europe/London |
| Review or stop | Review on December 13. Cancel the schedule when the project ends or replace its task text for the next goal. |
| Completion evidence | A dated note containing the three priorities and their next actions. |
| Saved result | The weekly review note in Daily Desk. |
| If unfinished | At the next conversation, choose a ten-minute review or move this week's work into the next review. |
| Requested action | Create Weekly review after checking the active reminders for an existing match. |
| Confirmation to save | Reminder title, weekly interval and the next Sunday at 18:00. |
| Schedule check | Open Upcoming and record the displayed next occurrence and the time checked. |

Give Muse the request:

```text
Every Sunday at 6 p.m. in Europe/London, remind me to review last week,
check my portfolio goal and choose three priorities. Call it Weekly review.
Show my active reminders first and update a matching Weekly review if it
already exists. Confirm the next date, time and repeat interval.
```

When the reminder arrives, save the review note. Track the reminder message and the completed review separately: the dated note is what tells you the review is finished.

## If a reply is interrupted

Open Upcoming or ask for the active reminders. Match the assistant, title, task text and schedule before sending another create request. If the reminder is present, continue with it. If its time is wrong, update that reminder. If several entries match, identify the one to keep before removing a duplicate.

If the requested time has passed, choose a new time and check the resulting schedule. Keep the existing task and its completion record together through the change.
