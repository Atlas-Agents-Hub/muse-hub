# Practice Scientific Computing

Build and check a numerical solution while making the mathematical choices explicit.

## Bring these inputs

- A concrete numerical problem
- Input data, units, and accuracy target

## 1. Linear Algebra Practice

Read [the Linear Algebra Practice method](../skills/linear-algebra-practice/SKILL.md). Represent the problem as a linear system and inspect scale, rank, and conditioning.

**Carry forward:** A matrix formulation with a selected decomposition.

**Check:** Dimensions, rank assumptions, and the decomposition match the problem.

## 2. Numerical Optimization

Read [the Numerical Optimization method](../skills/numerical-optimization/SKILL.md). Solve the formulation with a baseline and a documented stopping rule.

**Carry forward:** A reproducible solver configuration and convergence record.

**Check:** The solution meets the stopping rule and respects constraints.

## 3. Interactive Science Plots

Read [the Interactive Science Plots method](../skills/interactive-science-plots/SKILL.md). Visualize residuals and sensitivity to the important assumptions.

**Carry forward:** A plot set and a short explanation of sensitivity.

**Check:** Residuals and limiting cases support the claimed accuracy.

## Check the finished work

- Dimensions, rank assumptions, and the decomposition match the problem.
- The solution meets the stopping rule and respects constraints.
- Residuals and limiting cases support the claimed accuracy.

## Finish

A plot set and a short explanation of sensitivity. Residuals and limiting cases support the claimed accuracy.
