# Build and Profile a Game Feature

Deliver a playable feature with measurable frame-time and resource targets.

## Bring these inputs

- Game design brief and engine project
- Target hardware and performance budget

## 1. 3D Design

Read [the 3D Design method](../skills/3d-designer/SKILL.md). Prepare assets with scale, materials, topology, and export settings suited to the engine.

**Carry forward:** Engine-ready assets and an import specification.

**Check:** Scale, pivots, materials, and file formats survive import.

## 2. Game Developer

Read [the Game Developer method](../skills/game-developer/SKILL.md). Implement the feature and connect the prepared assets to gameplay.

**Carry forward:** A playable scene with defined success and failure states.

**Check:** Gameplay behavior and collision or physics responses match the brief.

## 3. Performance Profiler

Read [the Performance Profiler method](../skills/performance-profiler/SKILL.md). Measure the feature under the target scene load and address the largest bottleneck.

**Carry forward:** Before-and-after frame-time and memory results.

**Check:** The target budget is met without changing the intended gameplay.

## Check the finished work

- Scale, pivots, materials, and file formats survive import.
- Gameplay behavior and collision or physics responses match the brief.
- The target budget is met without changing the intended gameplay.

## Finish

Before-and-after frame-time and memory results. The target budget is met without changing the intended gameplay.
