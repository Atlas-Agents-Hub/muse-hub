# Improve Search Discovery

Improve site discovery with useful pages, crawlable structure, and accurate metadata.

## Bring these inputs

- Site URL and priority user questions
- Available analytics and search-console evidence

## 1. SEO Audit

Read [the SEO Audit method](../skills/seo-audit/SKILL.md). Inspect crawlability, indexation, content intent, and on-page metadata.

**Carry forward:** A prioritized SEO finding list tied to real pages.

**Check:** Each finding has observable evidence and a proposed user or discovery benefit.

## 2. Site Architecture

Read [the Site Architecture method](../skills/site-architecture/SKILL.md). Organize the pages and internal links around the priority questions.

**Carry forward:** A page and internal-link plan with canonical routes.

**Check:** Important pages are reachable and duplicate intent is handled deliberately.

## 3. Schema Markup

Read [the Schema Markup method](../skills/schema-markup/SKILL.md). Add structured data that matches the visible page content.

**Carry forward:** Validated metadata and structured data for the revised pages.

**Check:** Markup is truthful, syntax-valid, and consistent with the rendered page.

## Check the finished work

- Each finding has observable evidence and a proposed user or discovery benefit.
- Important pages are reachable and duplicate intent is handled deliberately.
- Markup is truthful, syntax-valid, and consistent with the rendered page.

## Finish

Validated metadata and structured data for the revised pages. Markup is truthful, syntax-valid, and consistent with the rendered page.
