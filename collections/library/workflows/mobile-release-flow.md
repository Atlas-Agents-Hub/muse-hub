# Prepare a Mobile App Release

Take a mobile feature through interaction checks and a controlled release package.

## Bring these inputs

- Feature requirements and app project
- Supported devices and release channel

## 1. React Native

Read [the React Native method](../skills/react-native-expert/SKILL.md). Implement the feature with platform-aware navigation, data, and permissions.

**Carry forward:** A working feature and device test plan.

**Check:** The feature handles loading, denial, interrupted use, and navigation correctly.

## 2. Software Test Design

Read [the Software Test Design method](../skills/test-master/SKILL.md). Run the relevant unit, integration, and device journey checks.

**Carry forward:** A release candidate with reproducible test results.

**Check:** The main journey and its failure cases pass on the target configurations.

## 3. Mobile Release

Read [the Mobile Release method](../skills/mobile-release/SKILL.md). Prepare versioning, artifacts, rollout, monitoring, and rollback actions.

**Carry forward:** A release package and channel-specific rollout checklist.

**Check:** The artifact, version, signing configuration, and release notes agree.

## Check the finished work

- The feature handles loading, denial, interrupted use, and navigation correctly.
- The main journey and its failure cases pass on the target configurations.
- The artifact, version, signing configuration, and release notes agree.

## Finish

A release package and channel-specific rollout checklist. The artifact, version, signing configuration, and release notes agree.
