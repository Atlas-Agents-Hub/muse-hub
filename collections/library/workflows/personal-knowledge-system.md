# Organize a Personal Knowledge System

Make useful information easy to capture, retrieve, and develop over time.

## Bring these inputs

- A bounded collection of files and notes
- Current projects and retrieval needs

## 1. File Organizer

Read [the File Organizer method](../skills/file-organizer/SKILL.md). Inventory the collection and group files by purpose while preserving originals.

**Carry forward:** A proposed folder map and duplicate review list.

**Check:** Files remain traceable and ambiguous duplicates are not discarded.

## 2. Para Method

Read [the Para Method method](../skills/para-method/SKILL.md). Organize active projects, responsibilities, resources, and archives.

**Carry forward:** A working information structure with clear filing rules.

**Check:** A representative item can be filed and retrieved without guessing.

## 3. Zettelkasten

Read [the Zettelkasten method](../skills/zettelkasten/SKILL.md). Turn selected useful material into linked notes with source references.

**Carry forward:** A small linked-note set and a repeatable capture routine.

**Check:** Links express meaningful relationships and source context remains available.

## Check the finished work

- Files remain traceable and ambiguous duplicates are not discarded.
- A representative item can be filed and retrieved without guessing.
- Links express meaningful relationships and source context remains available.

## Finish

A small linked-note set and a repeatable capture routine. Links express meaningful relationships and source context remains available.
