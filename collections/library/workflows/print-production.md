# Prepare Artwork for Print

Deliver artwork that matches the printer’s actual production requirements.

## Bring these inputs

- Approved message and artwork
- Printer specification sheet and intended physical format

## 1. Graphic Designer

Read [the Graphic Designer method](../skills/graphic-designer/SKILL.md). Develop the composition and asset hierarchy for the physical format.

**Carry forward:** An artwork layout with linked source assets.

**Check:** The message hierarchy works at the intended reading distance.

## 2. Typography

Read [the Typography method](../skills/typography-expert/SKILL.md). Refine type, spacing, and text flow for the paper and audience.

**Carry forward:** A checked typographic layout.

**Check:** Text remains legible and critical content fits within the agreed safe areas.

## 3. Print Designer

Read [the Print Designer method](../skills/print-designer/SKILL.md). Preflight and export using the printer’s profile, bleed, and proof requirements.

**Carry forward:** A press PDF, production specification, and proof approval.

**Check:** The exported file passes the printer-specific checks and matches the approved proof.

## Check the finished work

- The message hierarchy works at the intended reading distance.
- Text remains legible and critical content fits within the agreed safe areas.
- The exported file passes the printer-specific checks and matches the approved proof.

## Finish

A press PDF, production specification, and proof approval. The exported file passes the printer-specific checks and matches the approved proof.
