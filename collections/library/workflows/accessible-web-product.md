# Build an Accessible Web Interface

Turn a product flow into a responsive interface with consistent components and states.

## Bring these inputs

- User journey and content
- Existing components, browser targets, and accessibility needs

## 1. UI Design System

Read [the UI Design System method](../skills/ui-design-system/SKILL.md). Define the tokens, component states, and page structure for the journey.

**Carry forward:** A component specification and state inventory.

**Check:** Tokens and states support the actual content and interaction needs.

## 2. React Development

Read [the React Development method](../skills/react-expert/SKILL.md). Implement the journey using the agreed components and data boundaries.

**Carry forward:** A working interface with loading, empty, success, and error behavior.

**Check:** State transitions and data updates match the specification.

## 3. Design QA

Read [the Design QA method](../skills/design-qa/SKILL.md). Inspect the rendered interface at narrow and wide sizes and with keyboard navigation.

**Carry forward:** Resolved visual and accessibility findings with captured results.

**Check:** The key journey completes without clipping, inaccessible controls, or broken recovery.

## Check the finished work

- Tokens and states support the actual content and interaction needs.
- State transitions and data updates match the specification.
- The key journey completes without clipping, inaccessible controls, or broken recovery.

## Finish

Resolved visual and accessibility findings with captured results. The key journey completes without clipping, inaccessible controls, or broken recovery.
